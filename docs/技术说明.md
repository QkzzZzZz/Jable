# 技术说明（Windows 版）

## 技术选型
- C# / .NET 8 + WPF + WebView2。没有用 WinUI 3：只用命令行（不装 Visual Studio）编译 WinUI 3 不稳；WPF 是 .NET SDK 自带的。
- 播放放在 WebView2 里做，不用 VLC 这类独立播放器：视频服务器只认真实浏览器发出的请求。

## 读取与播放原理
**读取页面**：每个站点用一个隐藏的 WebView2。第一次访问时正常打开一次页面（Cloudflare 由浏览器内核自己通过，需要点击时会显示出来让你点）。之后的列表、详情都在这个页面里用 `fetch` 取 HTML：请求仍由浏览器发出、带同一份 cookie，但不渲染整页、不跑广告脚本。一页从 3～10 秒降到 0.2～0.6 秒。fetch 拿到的如果是验证页，就退回正常打开。HTML 在后台线程解析，缓存 5 分钟；会预读下一页，鼠标在卡片上停 0.3 秒也会预读该作品的详情页。

**播放**：先从（通常已缓存的）播放页 HTML 里取出播放地址（Jable 是 `hlsUrl` 变量）。然后播放窗口照常打开播放页的网址，但这个请求被程序在本地应答，换成自带的播放器页面（hls.js 1.5.17 + `Player/player.js`）。网址没变，所以同源、cookie、跨域都和真实页面一样，只是不再加载站点的网页和广告。实测 Jable 约 2 秒开始播放。取不到地址时，退回「打开真实播放页、等页面脚本生成地址」。

**不做的事**：不伪造浏览器指纹，不自动破解人机验证。所有请求都是真实浏览器内核发出的正常访问。

所有 WebView2 共用一个用户数据目录（`%LOCALAPPDATA%\JableLens\WebView2`），验证只需要过一次。网络请求按主机白名单放行，名单外的（广告、统计）一律拦掉。

## 嵌入网站（黄果短剧）
用真实网页（封面图由网站自己的脚本解密，软件不解密），放在单独的浏览器数据目录里，cookie 和看片的站点分开。软件注入样式和脚本，按 Jable 的样子整理页面：
- 藏掉网站自己的顶栏、侧栏、公告条、页脚、悬浮下载、换地址公告和所有广告位；广告脚本和统计请求直接拦截；首页轮播里的广告自动跳过。
- 栏目切换和搜索放到软件自己的信息栏里；配色、字体（MiSans，由软件自己提供给页面）、卡片网格、胶囊按钮和 Jable 一致。
- 涉及未成年人的作品、真人换脸作品不显示。
- 入口地址会跳到随机镜像域名，软件跟着服务器重定向走；点到站外的链接交给系统浏览器。

## 代码结构
- `src/JableLens.Core`：数据层（不依赖界面）
  - `Sources/Jable`：页面解析（AngleSharp）
  - `Sources/Netflav`、`Sources/Av01`、`Sources/R18`：JSON / 内嵌 JSON
  - `Subtitles`：subtitlecat 搜索 / 下载、.srt 解析、对时
  - `Names`：演员名对应；`Library`：历史、收藏、关注、新作检查、设置
  - `Http`：统一 HttpClient，**只允许访问白名单主机**
- `src/JableLens.App`：WPF 界面
  - `Services/WebPageReader`：WebView2 读页面（轮询就绪、提前停止加载、人机验证提示）
  - `PlayerWindow` + `Player/player.js`：播放器
  - `Pages/`：各页面；`Controls/`：卡片网格、毛玻璃背景、窗口框架、动画等
- `tools/JableLens.Cli`：命令行试用数据层
- `tests/JableLens.Core.Tests`：单元测试，样本在 `Fixtures/`（2026-10 抓的真实页面）

安卓版在单独的仓库 Jable-Android，带一份自己的 Core 副本。

## 本地数据
都在 `%LOCALAPPDATA%\JableLens`：`library.json`（历史 / 收藏 / 关注 / 设置）、`name-map.json`（演员名缓存）、`img`（图片缓存）、`error.log`（出错记录）。

## 调试
- `JABLELENS_DATA=<目录>`：全部数据（含 WebView2 cookie）存到这个目录，窗口标题带 (dev)，可以和正式使用的那份同时开。
- `JABLELENS_PERF=1`：每次读取和播放启动的耗时写到 `%LOCALAPPDATA%\JableLens\perf.log`。
- 启动参数：`--open <番号>`、`--page <栏目> [站内路径]`、`--performer <名字>`、`--play <播放页地址>`、`--probe <地址> <输出文件>`（把渲染后的 HTML 存下来看结构）。

## 2026-10 实测记录
1. **AV01 接口**：`POST https://www.av01.media/api/v1/videos/search?lang=cn`，body `{"query":"番号","pagination":{"page":1,"limit":20}}`。`lang` 只接受 jp/tw/hk/cn/kr/en/fr/th/vn/my/id/ph。演员译名在 `actresses[].name_translations`，简介在 `description_translations`。
2. **Netflav `searchActress` 不可靠**：搜「和香なつき」返回空。
3. **Netflav `sourceDate` 是上架时间，不是发行日**；同一番号会重复上架（如 [中字] 版），演员页按番号去重。`total/pages` 不准。
4. **Jable 显示的发行日可能比 R18 早一天**，R18 核对时两个日期都试。
5. **Jable 页面**：卡片 `.video-img-box`，标题 `.detail .title a`，封面 `img[data-src]`，预览 `data-preview`；播放页 `var hlsUrl = '...m3u8'`（标准 AES-128 HLS）；演员 `.models a.model [data-original-title]`；分页 `/栏目/页码/`。
6. **Netflav 演员目录档位**：年龄 2 超年輕、3 年輕、4 輕熟女、5 熟女、6 四十路；身高 1 &lt;160 … 6 180+；胸围 1 &lt;28 … 11 44+；罩杯 A–M、O。
7. WebView2 打开 jable.tv 有时会出现 Cloudflare「Performing security verification」，一般几秒后自动通过。
